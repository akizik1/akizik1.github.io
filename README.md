# akizik1.github.io

My portfolio site: https://akizik1.github.io

## Where things are

```
index.html                  The whole site (layout, styles, texts in EN / TR / BG, scripts)
Alper_Kizik_CV.pdf          CV linked from the site (kept here so existing links keep working)
images/
  profile/profile.webp      Profile photo
  projects/
    scout/                  Scout Finder screenshots
    gezimap/                GeziMap screenshots
    pano/                   Pano screenshots
    cro/                    Shopify CRO Checker screenshots
  baileys/
    sleep.webp, awake.webp  Baileys' corner badge (asleep / awake)
    gallery/                Baileys' photo gallery
```

## Common updates

- **Add photos of Baileys:** upload JPG, PNG, WEBP or GIF files to `images/baileys/gallery/`. They show up in his gallery automatically, sorted by file name.
- **Add a project:** put its screenshots in `images/projects/<id>/`, then copy a block in the `PROJECTS` list in `index.html` and set the same `id`.
- **Change a text:** English is in the page itself; Turkish and Bulgarian are in the `I18N` list in `index.html`.
